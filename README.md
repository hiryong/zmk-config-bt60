# BT60 V2 — ZMK config

Firmware for the Polarity Works BT60 V2 (60% ANSI), on the latest ZMK. Made to be copied with
**Make it yours** on [key.ryong.com](https://key.ryong.com), where keys, combos, macros and firmware
features are edited.

| | |
|---|---|
| Layout | Windows on the base layer; Mac on Fn + Tab (choose Mac as the base when you copy it) |
| Unlock for editing | Esc + Backspace together, or Fn + \ |
| Bootloader | Fn + Enter |
| Power | Off: Fn + Left Ctrl held 3 s · On: Fn + Left Ctrl held 3 s (only Fn wakes it) |
| Lights | Backlight and RGB underglow are off; switch them on in Settings |
| Bluetooth | Fn + Q / W / E / R = device 1–4 (the others are disconnected) |
